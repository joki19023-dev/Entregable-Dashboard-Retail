# Sistema de Inteligencia de Negocios en Excel - Retail

Este repositorio contiene el **Entregable Final** del programa de Business Intelligence, correspondiente a un sistema automatizado para una empresa ficticia de retail. 

## 📊 Contenido del Repositorio

1. **`Entregable_Final_BI_Retail.xlsx`**: El archivo principal de Excel que contiene el modelo de datos, gráficos avanzados (dispersión, cascada) y el Dashboard interactivo con segmentadores.
2. **`Registro_Prompts_IA.pdf`**: Documento de auditoría cognitiva. Detalla el uso de ChatGPT como "abogado del diablo" para evitar sesgos de confirmación (analizando estrategias de *Loss Leaders* y estacionalidad).

## 🚀 Características del Dashboard

- **Layout Profesional:** Fondo sobrio, eliminación de líneas de cuadrícula y paleta de colores corporativa.
- **KPIs Dinámicos:** Tarjetas con métricas clave y **formato condicional** que resalta el cumplimiento vs. la meta.
- **Capa Narrativa (Storytelling):** Títulos descriptivos y notas de análisis integradas directamente en la interfaz del Excel.
